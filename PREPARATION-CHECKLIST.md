# Student Preparation Checklist

**Project:** Group Expense Splitter  
**Goal:** Build a working application by solving a real-world problem using HTML, CSS, and JavaScript.

You do not need to know everything before joining. Use this checklist to get ready to learn and build with confidence.

## 1. Accounts and access

- [ ] I can sign in to my own GitHub account.
- [ ] I have submitted my correct GitHub username through the registration form.
- [ ] I can join Google Meet using my Google account.
- [ ] I can access the individual project repository shared by the trainer.
- [ ] I have accepted the GitHub repository invitation, if one was sent.

## 2. Laptop and development setup

- [ ] I have access to a laptop or desktop.
- [ ] I have a reliable internet connection.
- [ ] I can open the project repository in my browser.
- [ ] I have tested my audio and microphone for Google Meet.
- [ ] I know how to share my screen during a meeting.
- [ ] I can access the browser-based development environment specified by the trainer.
- [ ] If Codespaces access is ready, I have tried opening the assigned repository in Codespaces.

You do not need to install additional software unless the trainer asks you to. See the [GitHub Codespaces quickstart](https://docs.github.com/en/codespaces/quickstart) for help.

## 3. JavaScript fundamentals revision

You do not need to master every topic before the bootcamp. Just revise the basics.

- [ ] Variables: `let` and `const`
- [ ] Basic data types: strings, numbers, and booleans
- [ ] Arithmetic operations
- [ ] Conditions: `if`, `else if`, and `else`
- [ ] Functions, parameters, and return values
- [ ] Arrays and objects
- [ ] Loops: `for` and `for...of`
- [ ] Basic array methods: `map`, `filter`, and `find`

## 4. Think about the problem

Imagine three friends—Asha, Ravi, and Mina—share a hotel bill of ₹900. Asha pays the entire amount.

- [ ] I can explain how much each person should contribute.
- [ ] I can explain who owes money and who should receive money.
- [ ] I can think of how to represent people and expenses in JavaScript.
- [ ] I can identify questions we need to answer before building the application.

**Challenge question:** What changes if one person does not participate in an expense, or if different people pay for different expenses?

You do not need to solve every case now. Come prepared to discuss your approach.

## 5. Bootcamp commitment

- [ ] I have blocked the morning, afternoon, and evening sessions on my calendar.
- [ ] I will join sessions on time and participate actively.
- [ ] I will attempt problems before looking at a solution.
- [ ] I will ask questions when I get stuck.
- [ ] I will test my code and investigate errors rather than immediately giving up.
- [ ] I will make sure I understand and can explain the code I submit.
- [ ] I will use AI as a learning assistant, not as a replacement for my own thinking.

## 6. Final readiness check

Before the first session, confirm the following:

- [ ] My accounts and development environment are ready.
- [ ] I have revised the basic JavaScript concepts.
- [ ] I understand the problem we are going to solve.
- [ ] I am ready to attend the sessions and practise between them.
- [ ] I know where to ask for help if I face a setup issue.

## Remember

You are not expected to arrive as an expert programmer. The goal is to learn how to break down a real problem, design a solution, implement it, test it, debug it, and explain why it works.

**Come curious. Think independently. Build together.**
